# Planelo Projects

List all your Planelo projects or switch to a specific one.

## Usage

**List all projects:**
```
/projects
```

**Switch to a specific project:**
```
/projects TestersHub
/projects iOS-App
```

## What This Does

- Lists all available projects
- Shows project details (description, color, status)
- Helps you switch focus between projects
- Displays active tasks in each project
