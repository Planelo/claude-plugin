# List Planelo Ideas

View all tasks and ideas in your Planelo project, with filtering options.

## Usage

**Show all tasks:**
```
/list-ideas
```

**Filter by status:**
```
/list-ideas in_progress
/list-ideas idea
/list-ideas done
```

**Filter by priority:**
```
/list-ideas priority:high
/list-ideas in_progress priority:high
```

## Status Types

- **idea** - Not started yet
- **in_progress** - Currently working on
- **done** - Completed

## Priority Levels

- **high** - Critical/urgent
- **medium** - Normal priority
- **low** - Nice to have

## What This Shows

- Task title and description
- Current status
- Priority level
- Creation date
- Task ID (for reference)
